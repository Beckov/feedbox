# FeedBox FB-1 – stránka kŕmidla

Webová stránka k automatickému kŕmidlu pre akváriové ryby **FeedBox FB-1** od spoločnosti Aquaprint interactive s. r. o.

Obsah: rýchly štart, bezpečnostné pokyny, ovládanie a výpočet časov kŕmenia, význam signalizačných LED, riešenie problémov, údržba, technické údaje, návod na použitie (PDF), likvidácia, záruka a kontakt.

Stránku zobrazuje GitHub Pages (Settings → Pages → Deploy from a branch → main, / (root)). Na stránku vedie QR kód na obale výrobku.
